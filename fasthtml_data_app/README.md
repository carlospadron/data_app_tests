# FastHTML Data App

A FastHTML data application with interactive MapLibre visualization. See `FASTHTML.md` for the full implementation guide.

## Quick Start

```bash
cd fasthtml_data_app
uv sync
uv run python app.py
```

Open your browser to `http://localhost:5001`

## Features

- Interactive map with MapLibre GL JS
- Two data layers (regions and points of interest)
- Layer toggle controls with checkboxes
- Lightweight HTML-first structure with FastHTML
